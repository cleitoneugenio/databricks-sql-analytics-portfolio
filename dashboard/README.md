# Camada de visualização

O dashboard técnico foi construído no Databricks durante a análise. A versão de portfólio será publicada separadamente como uma página web, com identidade visual própria e narrativa voltada à tomada de decisão.

## Indicadores a apresentar

- taxa de atraso por estado, considerando estados com ao menos 100 pedidos;
- quantidade de pedidos atrasados e volume total de pedidos;
- comparação da nota média entre pedidos no prazo e atrasados;
- recomendações operacionais para os estados prioritários.

Quando a página estiver publicada, inclua aqui seu link público e, se desejar, uma captura em `../assets/`.

> O dashboard do Databricks permanece como evidência técnica do processo de análise; a página web será a vitrine pública do case.
